# App Idea Orchestrator

A dashboard that bridges **app-idea-agent** and **ai-web-team** into a unified control surface — with a React web dashboard, React Native mobile app, and a lightweight orchestrator backend.

## What it does

- **View all ideas** generated by app-idea-agent in a filterable card grid
- **Force Idea** — trigger the agent outside its cron schedule to generate new ideas immediately
- **Execute Idea** — hand an idea off to ai-web-team's 4-agent pipeline (PM → Designer → Architect → Developer)
- **Live progress** — watch each agent's streaming output in real-time via WebSocket relay
- **Push to GitHub** — one-click push of the completed project when the pipeline finishes
- **Mobile companion** — full feature parity on iOS/Android via Expo

## Architecture

```
app-idea-agent  (port 3001, Node.js/MongoDB)
      │
      │  REST + SSE
      ▼
app-idea-orchestrator/backend  (port 3003, Node.js/Express/SQLite)
      │               │
      │  REST          WS relay
      ▼               ▼
ai-web-team  ──────▶  Dashboard (React, port 5174)
(port 3002,           Mobile (Expo)
 Python/FastAPI)
```

## Quick Start

### Prerequisites
- **app-idea-agent** running on port 3001
- **ai-web-team backend** running on port **3002** (set `PORT=3002` in its `.env`)
- MongoDB running (for app-idea-agent)

### 1. Configure
```bash
cd backend
cp .env.example .env
# Edit .env — set IDEA_AGENT_URL and AI_WEB_TEAM_URL if needed
```

### 2. Install & run backend
```bash
cd backend
npm install
npm run dev
```

### 3. Run web dashboard
```bash
cd web
npm install
cp .env.example .env   # set VITE_API_URL if needed
npm run dev
# Opens at http://localhost:5174
```

### 4. Run mobile
```bash
cd mobile
npm install
npx expo start
```

Added to `server/routes/ideas.js`:
- `GET  /api/agent/stream` — SSE stream for real-time run notifications
- `POST /api/agent/force`  — explicit "force run" alias (same as `/agent/run` but with different SSE event type)
